# App registry (7.4)

Single table of built-in apps shared by the Start menu, desktop icons, and session restore.

## Registry fields

Each `AppRegistryEntry` in `src/window/AppRegistry.hpp` carries:

- `id` / `displayName` / `startMenuLabel`
- `appBaseTitle` (instance titling) and `sessionKey` (`session_v1` kind)
- `action` (`AppAction`) used by Start menu hit targets and desktop icons
- `startMenuCategory` (nullptr = top-level; `"Games"` nests under Games)
- `showInStartMenu` / `showDesktopIcon` / `desktopOrder`
- desktop glyph and tile color

## Consumers

- Start menu rows: `buildStartMenuRows()` (separator + category headers inserted automatically)
- Desktop icons: `collectDesktopIconDefs()` ordered by `desktopOrder`
- Launch dispatch: `WindowManager::launchByAction`
- Session save/load: `findAppByBaseTitle` / `findAppBySessionKey`

Adding an app is one registry row plus a `launchXxx` method and one `launchByAction` case.
