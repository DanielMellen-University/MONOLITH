# Wallpaper decode (slice 7.1)

Desktop wallpaper images load through `WallpaperImage`: BMP uses SDL's decoder and PNG/JPEG use pinned build-time `stb_image`. Settings stores a virtual FS path (`.bmp`/`.png`/`.jpg`/`.jpeg`). The Window Manager cover-scales the texture over the solid background. Empty or unloadable paths fall back to solid color only.
