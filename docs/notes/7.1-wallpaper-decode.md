# Wallpaper decode (slice 7.1)

Desktop wallpaper images load BMP via `SDL_LoadBMP` and PNG/JPEG via pinned build-time `stb_image` (`WallpaperImage`). Settings stores a virtual FS path (`.bmp`/`.png`/`.jpg`/`.jpeg`). The Window Manager cover-scales the texture over the solid background. Empty or unloadable paths fall back to solid color only.
