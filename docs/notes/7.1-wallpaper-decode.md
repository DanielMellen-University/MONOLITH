# Wallpaper decode (slice 7.1)

Desktop wallpaper images load through `WallpaperImage`: BMP uses SDL's decoder and PNG/JPEG use pinned build-time `stb_image`. PNG/JPEG are inspected before decode, loaded directly from their host file instead of copying the entire compressed file into memory, and rejected above 16,777,216 pixels. Settings stores a virtual FS path (`.bmp`/`.png`/`.jpg`/`.jpeg`). The Window Manager cover-scales the texture over the solid background. Empty or unloadable paths fall back to solid color only.
