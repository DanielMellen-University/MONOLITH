# Wallpaper decode (slice 7.1)

Desktop wallpaper images load through `WallpaperImage`: BMP uses SDL's decoder and PNG/JPEG use pinned build-time `stb_image`. Dimensions for all formats are checked before pixel decoding and images above 16,777,216 pixels are rejected. BMP is checked from the same open file handle SDL later decodes; PNG/JPEG are loaded directly from their host file instead of copying the compressed file into memory. Settings stores a virtual FS path (`.bmp`/`.png`/`.jpg`/`.jpeg`). The Window Manager cover-scales the texture over the solid background. Empty or unloadable paths fall back to solid color only.
