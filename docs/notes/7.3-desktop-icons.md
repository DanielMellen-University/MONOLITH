# Desktop icons (7.3)

Optional desktop app icons on the wallpaper layer (multi-column since 7.7).

## Behavior

- Icons: Terminal, Filesystem, Editor, Drawing, Settings (Games stay under Start).
- Drawn after wallpaper and before windows, so overlapping windows always win visually.
- Clicks reach icons only when `getWindowAt` misses every window (and after taskbar/Start handling).
- Single-click selects; double-click within 450 ms launches via existing WindowManager launchers.
- Double-click timing uses unsigned SDL tick elapsed time, so the 32-bit tick counter wrapping does not discard a valid second click.
- Clicking a window, taskbar, Start menu, Alt+Tab, or empty desktop clears both the selection and any pending double-click history, so unrelated clicks cannot trigger a launch.
- Enter launches the selected icon when no visible window has keyboard focus.
- Short usable desktops fill additional columns left-to-right (top-to-bottom within each column) and still omit icons that cannot fit entirely instead of crowding the taskbar or clipping past the right edge. See `docs/notes/7.7-desktop-icon-columns.md`.
- Each icon reserves a stable 112-pixel label cell, so longer labels stay inside their cell; narrow desktops omit icons rather than letting text bleed into the workspace.
- The first icon row is allowed when its tile and label exactly fit the usable height; later rows also reserve the configured inter-icon gap.
