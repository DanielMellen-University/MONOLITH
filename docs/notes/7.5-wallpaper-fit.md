# Wallpaper fit modes (7.5)

Settings persists `wallpaper_fit=cover|contain|center` (default `cover`) and the Window Manager paints accordingly.

## Modes

- **cover** (default): fill the logical desktop, crop overflow, centered. Same behavior as before this chunk.
- **contain**: entire image visible; letterbox/pillarbox shows the solid desktop background.
- **center**: natural 1:1 centered; clip if larger than the desktop; solid background around.

Unsupported or malformed values coerce to `cover` on load and on set.

## Wire

- `DesktopSettings`: `wallpaperFit()` / `setWallpaperFit()`; key `wallpaper_fit=`
- `IWindowController` / `WindowManager`: get/set live apply + persist
- Settings APPEARANCE: Cover / Contain / Center options near the wallpaper path controls (white-border active)
