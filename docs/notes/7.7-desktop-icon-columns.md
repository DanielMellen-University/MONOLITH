# Multi-column desktop icons (7.7)

`layoutDesktopIcons` fills additional columns left-to-right when the usable height cannot hold every registry desktop icon in a single column.

## Behavior

- **Order**: top-to-bottom within a column, then the next column to the right (classic desktop).
- **Step**: columns advance by `kDesktopIconColStep` (`kDesktopIconCellW + kDesktopIconGap`) so label cells never overlap.
- **Omit**: icons that cannot fit entirely inside usableWidth x usableHeight stay omitted (no taskbar overlap, no clip past the right edge).
- Hit testing, double-click timing, and `DesktopIconPlacement` fields are unchanged.

## Wire

- Layout: `src/window/DesktopIcons.hpp` (`layoutDesktopIcons`)
- WM still calls `layoutDesktopIcons` from `wm_desktop_icons.inc`
- Headless coverage: `scripts/test_desktop_icons.cpp`
- Static checks: `scripts/verify_desktop_icons.sh`
